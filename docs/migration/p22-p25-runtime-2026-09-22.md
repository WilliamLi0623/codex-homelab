   of being incorrectly persisted as an `UNKNOWN` capacity claim.
2. `git add` and `git commit` failures preserve bounded command output.
3. Muse Chat Completions sends `tool_choice=required` on the initial request,
   then uses default `auto` after tool results so the model can finish.
4. The GLM/Muse tool loop fails closed when no terminal call was observed.
5. The worker prompt now states that the worker must use terminal but must not
   run `git commit` or `git push`; the wrapper owns validation and local commit.
6. If an agent has already created a new commit after validation, the wrapper
   accepts that new SHA only when it differs from the recorded base SHA and is
   a valid 40-character commit.
